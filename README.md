# 🤖 DuoSup Blox Fruits API

Private API gateway for DuoSup.

This service is designed to provide Blox Fruits:

- 🍎 Normal Stock
- 🌙 Mirage Stock
- 💰 Beli prices
- 💎 Robux prices
- ⏱ reset information

The service is intended to run on Railway.
